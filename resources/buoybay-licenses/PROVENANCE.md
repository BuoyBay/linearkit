# Provenance

Independent implementation for the Buoy foundations coverage plan. No third-party
source or native numerical library is vendored. LU partial pivoting and
Householder reflections are standard algorithms; Python Fraction oracle code is
independent exact elimination/projection, not a translation of the Buoy solver.
Scope is the finite dense API in README.md, not compatibility with another package
or a claim of complete numerical linear algebra. No upstream code license is added.
